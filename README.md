# Kodawari

I'm the developer behind [Kodawari](https://kodawaristudio.fr), a small software studio. I build websites, business tools and AI agent systems, and I spend more time than I should on the details nobody sees.

Two small open source tools in Rust are on the way:

- **kanso** lints the instruction files that coding agents read (AGENTS.md, CLAUDE.md, SKILL.md and friends): token budget, dead links, duplicates, leaked secrets.
- **kioku** remembers which tests and builds already passed on the exact same code, so agents and CI stop running them twice.

They'll show up here once they're tested and documented.
